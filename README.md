## 🚀 Overview
The **Literary Expansion Architect** is a specialized creative tool designed for authors, screenwriters, and researchers. By analyzing an initial "seed" text, it extracts the underlying stylistic fingerprints—vocabulary, syntax, tone, and pacing—and uses them to autonomously generate continued narratives, supplementary chapters, or technical elaborations that are indistinguishable from the original source.

## ✨ Key Features
- **Style DNA Analysis**: Deep semantic profiling of the author's unique voice.
- **Autonomous Continuation**: Generates logical extensions of plots or technical arguments.
- **Consistency Guardrails**: Ensures characters, terminology, and themes remain coherent over long projects.
- **Multi-Genre Support**: Optimized for both creative fiction and technical whitepaper expansion.

## 🛠️ Tech Stack
- **Frontend**: Vite + React + TypeScript
- **AI Core**: Google Gemini 2.0 Flash
- **Styling**: Tailwind CSS
- **Orchestration**: Custom prompt chaining for style preservation

## 🎮 Getting Started

### Installation
1.  **Clone & Install**:
    ```bash
    npm install
    ```
2.  **Environment**:
    Create `.env.local` and add `GEMINI_API_KEY=your_key_here`.
3.  **Run**:
    ```bash
    npm run dev
    ```
